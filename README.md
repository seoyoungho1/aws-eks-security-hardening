## 📌 1. 프로젝트 개요
* **추진 배경:** 클라우드 보안 사고의 대다수는 인프라 자체의 결함이 아닌 **사용자의 미흡한 보안 설정과 관리 부주의**에서 발생합니다. 수동 점검의 한계를 극복하고, 스크립트 실행만으로 보안 상태를 검사·적용할 수 있는 자동화 도구를 기획했습니다.
* **프로젝트 목적:**
  * **IaC 보안 자동화:** Terraform 코드 기반 `Checkov`를 연동하여 배포 전 단계에서 취약 설정 사전 차단
  * **원클릭 진단 및 조치:** 스크립트를 통한 손쉽고 빠른 AWS 보안 취약점 검사 및 안전한 설정 자동 적용
  * **실시간 모니터링 체계:** `Prometheus`와 `Grafana` 연동을 통한 서버 가동 상태 및 메트릭 시각화 관제

## 🛠️ 2. 주요 기술 스택 및 역할
| 구분 | 기술명 | 주요 역할 및 설명 |
| :--- | :--- | :--- |
| **인프라 IaC** | **Terraform** | 코드를 통한 AWS 클라우드 인프라(VPC, Subnet, EKS) 자동 구축 및 관리 |
| **오케스트레이션** | **AWS EKS & Kubernetes** | 클라우드 쿠버네티스 클러스터 구축 및 Nginx 웹 서버 Pod 배포 |
| **보안 진단** | **Checkov** | Terraform 코드 상의 보안 취약점과 설정 오류를 배포 전 단계에서 정적 진단 |
| **모의 해킹** | **Kali Linux, Prowler** | 실제 배포된 인프라의 보안 상태 및 컴플라이언스 준수 여부 심층 진단 |
| **자동화 파이프라인** | **PowerShell Script** | 진단, 리포트 분석, Terraform 배포, EKS 클러스터 업데이트까지 원클릭 처리 |
| **실시간 관제** | **Prometheus & Grafana** | 노드 리소스 및 워크로드 상태를 실시간 수집하고 대시보드로 시각화 |
